# Git 命令速查手册

一个单页 Git 命令速查工具，分类整理开发者高频使用的 Git 命令，支持关键词搜索和一键复制，开箱即用。

## 功能

- 9 个分类、90 条高频命令：初始配置、仓库操作、提交与暂存、分支管理、撤销与回退、远程同步、查看历史、标签管理、储藏与杂项
- 每条命令带中文说明，危险命令标有「慎用」提示
- 顶部搜索框，输入关键词（如「撤销」「branch」）即时过滤并显示命中数
- 每条命令一键复制到剪贴板
- 分类标签可单独筛选并定位；支持 Ctrl/Cmd+K 快速聚焦搜索
- 响应式布局，手机和电脑均可正常使用；适配深色模式

## 使用方法

直接用浏览器打开 `index.html` 即可使用，无需安装、无需联网、无需后端。

## 技术栈

HTML5 + CSS3 + 原生 JavaScript，零依赖，单个文件即完整应用。
